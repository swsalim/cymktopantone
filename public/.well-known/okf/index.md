# Color Mapper

> Color Mapper (colormapper.xyz) is a free color toolkit that runs in the browser, with no account required.

## What this business does

Color Mapper offers palette and gradient generators, a WCAG 2.1 contrast checker, a Tailwind-style 50–950 tint and shade scale builder, a print gamut checker, an image palette extractor, a color blindness simulator, a Delta E 2000 color comparator, and 18 converters between RGB, CMYK, HEX, HSL, and HSV. It is print-aware: swatches carry CMYK values and out-of-gamut colors are flagged. Exports include CSS custom properties, Tailwind theme.extend.colors, and JSON tokens.
