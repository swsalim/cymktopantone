# Color Mapper color tools

All tools are free, run in the browser, and need no account.

- [Palette generator](https://colormapper.xyz/palettes): six harmony rules (complementary, analogous, triadic, split complementary, monochromatic, tetradic) from one seed color; lock swatches, export CSS, Tailwind, or JSON; flags out-of-gamut colors.
- [Gradient generator](https://colormapper.xyz/gradients): linear, radial, and conic CSS gradients with up to five stops.
- [Contrast checker](https://colormapper.xyz/contrast-checker): WCAG 2.1 ratios with AA/AAA badges, auto-fix suggestions, and a palette matrix.
- [Tint and shade scale](https://colormapper.xyz/color-scale): one HEX in, a Tailwind-style 50–950 ramp out, contrast-checked per step.
- [Palette from image](https://colormapper.xyz/palette-from-image): extracts dominant colors from a photo in the browser; images are not uploaded.
- [Color blindness simulator](https://colormapper.xyz/color-blindness): previews palettes under protanopia, deuteranopia, and tritanopia.
- [Color wheel](https://colormapper.xyz/color-wheel): interactive wheel with live harmonies.
- [Print gamut checker](https://colormapper.xyz/print-gamut): shows how a screen RGB color shifts on a CMYK press.
- [Compare colors](https://colormapper.xyz/compare-colors): Delta E 2000 perceptual difference between two colors.
